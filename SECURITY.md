# Sicurezza

similFranz Monitor per Android è un simulatore per la simulazione sanitaria: non è un dispositivo medico e non tratta
dati clinici reali. Il monitor apre però un piccolo server HTTP (porta 8080, protetto dal PIN) e un collegamento Wi-Fi
Direct®: se trovi un modo per comandarlo senza PIN, leggere ciò che non dovresti o disturbare una simulazione, segnalalo.

## Come segnalare

- Usa **Security → Report a vulnerability** (segnalazione privata) in questa repo, non una segnalazione pubblica.
- Scrivi la versione dell'app (menu ☰ del monitor), il tablet, i passi per riprodurre il problema e che cosa succede.
- Ti rispondo appena posso; a correzione pubblicata la segnalazione può diventare pubblica, con il tuo nome se vuoi.
